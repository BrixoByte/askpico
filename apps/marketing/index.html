Under the hood

Built in layers.

Three parts that work together: routing, character and live previews.

01 · Routing

Agent Router Engine

Reads each request and sends it to the agent that fits. Simple questions stay fast. Hard tasks get the right model.

  • Picks the agent in milliseconds
  • Keeps latency low for voice
  • Shows one clean result
02 · Character

Character Assistant

A friendly voice that reacts to your mood and keeps replies human, with a light touch of humor where it fits.

  • Mood-aware replies
  • Uses your name when known
  • Never pretends to be human
03 · Preview

Real-time Artifact Preview

Pages, charts and small apps appear next to the chat as you talk, so you see the result before you ask for changes.

  • Live preview beside the chat
  • Edit by voice or by text
  • Copy the code when you are happy
